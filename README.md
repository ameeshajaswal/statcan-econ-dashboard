# Canadian Economic & Labour Market Dashboard
 
## Overview
 
An automated economic intelligence dashboard built using Statistics Canada APIs, Python, Prophet forecasting, and Power BI.
 
## Key Features
 
- Automated Statistics Canada data ingestion
- Labour Market Health Index
- Unemployment forecasting using Prophet
- Automated executive economic commentary
- Interactive Power BI dashboard
- Economic Outlook analysis
 
## Dashboard Pages
 
1. Labour Market Overview
2. Wages & Inflation
3. GDP & Economic Activity
4. Economic Outlook
 
## Technology Stack
 
- Python
- Pandas
- Prophet
- Power BI
- GitHub Actions
- Statistics Canada WDS API
